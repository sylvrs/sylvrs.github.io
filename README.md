# Em's Funny Portfolio

A terminal-inspired portfolio website built with my favorite web technologies:
- Bun - The JS runtime for development and building
- SolidJS / Astro - Frontend framework + SSG for building our site
- Tailwind / DaisyUI - For styling & making things look nice
- TypeScript - For type safety and/or better development experience
